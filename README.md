# Student Grade Analyzer 🎓

A simple Python project built using **Pandas** and **NumPy** to analyze student test scores, calculate averages, and determine pass/fail status.

## 🚀 Features
- Loads student data from a CSV file (`output_file.csv`)
- Calculates average marks across subjects using NumPy row-wise operations
- Automatically assigns `Pass` or `Fail` status based on performance
- Exports/prints structured results cleanly

## 🛠️ Tech Stack
- **Python**
- **Pandas**
- **NumPy**
